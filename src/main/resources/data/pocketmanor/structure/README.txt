Drop your saved manor build here as:

    manor.nbt

(so the full path is data/pocketmanor/structure/manor.nbt)

When that file is present, the mod stamps YOUR build into the manor dimension
instead of generating the built-in coded manor. See DESIGN.md in the repo root
for the full step-by-step. Note the folder is "structure" (singular) - that is
the Minecraft 1.21 datapack convention.

This README.txt is ignored by the game; only .nbt files are loaded.
